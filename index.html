Experience input

Add each game as a role: organization, title, dates, hours, and the work you actually did. Use notes for anything a recruiter must not misunderstand, such as a volunteer community role.

Steam’s Web API does not accept calls from a website. Start this folder with py -3 serve.py and open http://localhost:8080. That program runs on this computer, asks Steam for your games, and sends nothing to a third party. Leave the CORS proxy field blank.

The profile must expose game details. In Steam: Edit Profile, then Privacy Settings, then set Game details to Public. Achievement history also has to be public, and some games publish no stats.
